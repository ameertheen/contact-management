# Contact Management System

A full-stack Contact Management application built using Angular 16, Spring Boot, and SQLite.

## Technology Stack

- Java 17
- Spring Boot 3.x
- SQLite
- Angular 16
- Bootstrap 5
- GitHub Actions

## Features

- Create contacts
- View all contacts
- View contact details
- Update contacts
- Delete contacts
- Search contacts
